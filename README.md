## 🏗️ Real-World Asset (RWA) Infrastructure

This is where Veil Protocol becomes transformational. The RWA sector is projected to reach **$16 trillion by 2030** (BlackRock, BCG estimates). We're building the privacy rails for every dollar of it.

### 🏠 Private Real Estate Tokenization

Tokenizing real estate has always had a fundamental problem: property ownership, valuations, and transaction history are sensitive. Public ledgers expose everything.

Veil Protocol enables:
- **Confidential property tokenization** — mint fractional ownership tokens without revealing the underlying asset valuation on-chain
- **ZK-verified title transfers** — prove legal ownership transfer without exposing buyer/seller identity
- **Private rental yield distribution** — distribute income to token holders with encrypted payment rails
- **Compliance attestation without data exposure** — prove KYC/AML compliance to regulators without sharing personal data
- **Cross-border property investment** — private settlement across jurisdictions with ZK regulatory proofs

Real estate funds can now tokenize portfolios worth hundreds of millions, distribute fractional ownership globally, and maintain full regulatory compliance — all without exposing sensitive financial data to competitors or the public.

### 📄 Confidential Invoice Financing

Invoice financing is a $3 trillion market plagued by opacity, fraud, and slow settlement. Veil Protocol transforms it:

- **ZK invoice verification** — cryptographically prove an invoice is authentic and unpaid without revealing the buyer, seller, or amount
- **Private auction for invoice purchase** — multiple lenders bid on invoices without seeing each other's offers
- **Automated ZK settlement** — smart contract releases funds the moment ZK proof of payment confirmation is received
- **Fraud-proof double-financing prevention** — ZK proofs guarantee an invoice can only be financed once, without a central registry
- **Supply chain finance at scale** — corporations can finance their entire supply chain privately through the protocol

Businesses that previously needed to share sensitive commercial relationships with banks can now access liquidity without exposing trade secrets.

### 🏦 Private Treasury Bond Issuance

Governments and corporations issue trillions in bonds annually. Veil Protocol brings bonds on-chain with institutional-grade privacy:

- **Anonymous bond subscription** — institutional buyers participate in bond auctions without revealing their position size
- **Private coupon payment rails** — interest payments distributed to verified holders without public address exposure
- **ZK credit rating attestation** — prove creditworthiness scores to counterparties without revealing the underlying financial data
- **Confidential secondary market trading** — bond trading with ZK-verified settlement and private order books
- **Regulatory reporting ZK proofs** — automatically generate compliance reports for regulators without exposing individual investor data

### 🔍 ZK Compliance Oracle

The single biggest blocker for institutional DeFi adoption is compliance. Institutions can't use protocols that make their activity public. Veil Protocol's Compliance Oracle solves this at the protocol level:

- **KYC/AML attestation without identity exposure** — prove a user passed verification without revealing who they are
- **Jurisdiction compliance proofs** — cryptographically prove a transaction is legal in a given jurisdiction
- **FATF Travel Rule compliance** — satisfy regulatory requirements for cross-border transfers with ZK proofs
- **On-chain audit trails** — generate auditable records for regulators that reveal nothing to the public
- **Automated sanctions screening** — screen against OFAC/SDN lists and generate ZK proofs of clearance in milliseconds
- **MiCA & SEC reporting** — produce regulator-specific compliance attestations automatically

This is the key that unlocks the institutional treasury. Hedge funds, family offices, and bank treasuries can now participate in DeFi without violating their compliance obligations.

### 🌑 Dark Pool DEX — Private Large Block Trading

On-chain large block trades are toxic. The moment a whale moves $50M in a public AMM, they're front-run, sandwiched, and exploited. Veil Protocol's Dark Pool DEX changes everything:

- **Zero-knowledge order matching** — buy and sell orders matched cryptographically; no one sees your position size or direction
- **MEV-immune settlement** — ZK proofs of fair execution eliminate miner/validator extractable value
- **Institutional-grade liquidity** — deep liquidity pools with privacy guarantees attract institutional market makers
- **Private limit orders** — place limit orders without broadcasting your target price to the market
- **Cross-chain dark pool routing** — find best execution across multiple chains without revealing your trading strategy
- **ZK proof of best execution** — prove to your investment committee you got the best price without revealing the counterparty

This is the infrastructure that brings hedge funds, asset managers, and proprietary trading desks on-chain for the first time.

## 🔐 Privacy Tooling Suite

Veil Protocol ships a complete, production-ready privacy toolkit accessible directly in the browser:

### Cryptographic Key Management
- **RSA-2048 key pair generation** — enterprise-grade asymmetric encryption, generated client-side
- **AES-256-CBC encryption** — military-grade symmetric encryption for query results
- **Wallet-bound private keys** — encryption keys derived from and bound to your wallet signature
- **Anonymous session support** — generate encryption keys without connecting a wallet

- **Private result delivery** — responses encrypted to your public key before transmission
- **ZK proof verification UI** — inspect and verify the ZK proof attached to every oracle response
- **Query history encryption** — historical queries stored encrypted; only you can read them

## 🌐 Getting Started

### Prerequisites
- Node.js 18+
- PostgreSQL (or use Neon serverless)
- Phantom Wallet browser extension

### Installation

```bash
# Clone the repository
git clone https://github.com/HeroDappDev/Veil-Protocol.git
cd Veil-Protocol

# Install dependencies
npm install

# Configure environment variables
cp .env.example .env
# Add your API keys: OpenAI, Anthropic, Gemini, DB connection

# Start development server
npm run dev
```

The dev server spins up the Express API and Vite frontend together on a single port.

### Environment Variables

```env
DATABASE_URL=           # PostgreSQL connection string
OPENAI_API_KEY=         # OpenAI API key (GPT-4o)
ANTHROPIC_API_KEY=      # Anthropic API key (Claude Opus 4.5)
GEMINI_API_KEY=         # Google Gemini API key (Gemini 2.5 Pro)
```
