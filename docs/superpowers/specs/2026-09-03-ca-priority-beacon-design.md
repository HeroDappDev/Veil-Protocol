# CA Priority Beacon

## Goal

Make the contract-address status the most prominent interactive element beneath the Veil Protocol hero while preserving the existing neon terminal aesthetic.

## Design

- Replace the small pill with a larger rectangular beacon.
- Add a compact `CONTRACT ADDRESS` eyebrow above an oversized `COMING SOON` value.
- Use a high-contrast primary border, layered acid-green glow, and restrained ambient pulse.
- Keep the entire beacon clickable with a clearly visible copy icon and copied state.
- Preserve responsive sizing, keyboard focus visibility, and reduced-motion behavior.

## Scope

Only the homepage CA callout changes. Its existing clipboard and toast behavior remain unchanged.

## Verification

- Confirm the beacon dominates the CTA area without competing with the hero title.
- Confirm it remains readable and balanced on desktop and mobile.
- Confirm copy feedback remains visible.
